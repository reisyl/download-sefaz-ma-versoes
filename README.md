# Download de notas SEFAZ-MA: versões

Este repositório guarda **somente os instaladores** do programa Download de notas SEFAZ-MA e as notas de cada versão.
Não há código-fonte aqui.

- **Versões oficiais**: etiquetas `vX.Y.Z`.
- **Versões de teste**: etiquetas `vX.Y.Z-dev`, marcadas como *pre-release*.

O programa instalado consulta esta página para avisar quando há versão nova. Cada versão traz um
`manifesto.json` assinado digitalmente; o programa só instala um arquivo cuja assinatura e impressão
digital (SHA-256) conferem.
